מדיניות פרטיות

office-mail. בתוקף מ-15.10.2026.

נתונים

הודעות Gmail, תוויות, קבצים מצורפים, נתוני הודעה, וכתובת החשבון המחובר. הרשאות: gmail.modify, openid, email, profile (ובהפעלת יומן או משימות: calendar.events, calendar.freebusy, tasks).

שימוש

הצגה, מיון, סיכום, חיפוש והכנת טיוטות, במחשב של המשתמש. פעולות ב-Gmail רק בלחיצה של המשתמש.

שמירה

במחשב של המשתמש בלבד. אסימוני הגישה מוצפנים ב-Keychain של macOS. אין עותק בשרת.

שיתוף

אין מכירה, אין פרסום, אין טלמטריה, ואין אימון של מודלי AI כלליים. חריג לפי בחירת המשתמש: כשהוא בוחר ב-Claude (Anthropic) למשימה מסוימת, נשלח רק התוכן שהמשימה צריכה.

Google API Services

השימוש בנתונים מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

ביטול

ב-myaccount.google.com/permissions. הסרת החשבון בתוכנה מוחקת את העותק המקומי.

Privacy policy

office-mail. Effective October 15, 2026.

Data

Gmail messages, labels, attachments, message metadata and the connected account's address. Scopes: gmail.modify, openid, email, profile (and, if calendar or tasks are turned on: calendar.events, calendar.freebusy, tasks).

Use

Display, sorting, summaries, search and drafts, on the user's Mac. Actions in Gmail only when the user clicks.

Storage

Only on the user's Mac. Access tokens are encrypted in the macOS Keychain. No copy on any server.

Sharing

No sale, no advertising, no telemetry, no training of generalized AI models. One exception by the user's choice: when the user chooses Claude (Anthropic) for a specific task, only the content that task needs is sent.

Google API Services

office-mail's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation

At myaccount.google.com/permissions. Removing the account in the app deletes its local copy.
